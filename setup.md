
1. Clone the repository
   `git clone https://github.com/Ringo-Star/DiffuAgent-dllm.git`
2. Follow the setup instrauctions in "Quick Start" section shown at
   `https://github.com/Ringo-Star/DiffuAgent-dllm/tree/main?tab=readme-ov-file#quick-start`
   >**For Agentboard:** 
   >1) Clone repo as instructed in `https://github.com/Ringo-Star/DiffuAgent-dllm/blob/main/DiffuAgent/Agentboard/installation.md` 
   >2) Follow `https://github.com/hkust-nlp/AgentBoard?tab=readme-ov-file#-quick-start` to set up env. No API key is needed as we are using open source models.
   >   
    **For BFCL:**
   >1) CLone repo as instructed in `https://github.com/Ringo-Star/DiffuAgent-dllm/blob/main/DiffuAgent/BFCL/installation.md`
   >2) Follow `https://github.com/ShishirPatil/gorilla/tree/main/berkeley-function-call-leaderboard#installation--setup`. Note that `sglang` has a wider coverage for LLM support including diffusion LLMs.

1. Running evaluations:

##### BFCL Eval

See `https://github.com/ShishirPatil/gorilla/tree/main/berkeley-function-call-leaderboard#running-evaluations` for examples.
